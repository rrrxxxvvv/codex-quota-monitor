# Codex Quota Monitor

Windows 桌面额度监控：读取本机已登录 Codex 的额度，额度重置或增加后显示持续置顶提醒；可按规则发送最小问候，并可将额度上传到 AstrBot，通过 QQ 查询和接收通知。

这是个人项目，不是 OpenAI 官方产品。只显示接口实际返回的额度窗口，不假定所有套餐都有五小时和周额度。

## 两个仓库的关系

| 项目 | 运行位置 | 职责 |
| --- | --- | --- |
| 本仓库 | 登录 Codex 的 Windows 电脑 | 采集额度、本地提醒、自动规则、上传 |
| [astrbot_plugin_codex_quota](https://github.com/rrrxxxvvv/astrbot_plugin_codex_quota) | 运行 AstrBot 的服务器 | 接收并按 QQ 保存额度、私聊查询和推送、重置卡到期提醒 |

只使用本地监控时不需要插件。需要 QQ 功能时必须安装两端；插件不能自行登录你的电脑查询 Codex。两端使用同一连接密钥，上传格式为 v2，路径为 `/v1/quota`。

## 环境依赖

- Windows，Windows PowerShell 5.1、.NET/WPF、Windows Script Host。界面不支持 Linux/macOS。
- Node.js 22 或更高版本，`node.exe` 位于 PATH；无需 `npm install`，仅使用 Node 内置模块。
- 本机安装并登录 Codex。脚本通过 `codex.exe app-server --stdio` 读取额度，需要对应版本提供 `account/rateLimits/read` 等接口。
- 默认查找 `%LOCALAPPDATA%\OpenAI\Codex\bin` 中的可执行文件，也会回退到 PATH 中的 `codex.exe`。可通过环境变量 `CODEX_QUOTA_CODEX_PATH` 指定完整路径。

## 启动

下载源码到可写目录，双击 `Start.vbs`。也可以从仓库目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Monitor.ps1
```

`Settings.vbs` 直接打开自动规则。关闭主窗口会收起到托盘；选择“退出监控”才停止。程序需保持运行，电脑睡眠或关机时不会采集。

默认每分钟采集一次；异常会退避重试。额度恢复或重置通知持续置顶，直到手动关闭。首次读取和账号切换只建立基线，不假报重置。

## 自动执行规则

在“自动执行规则”中新增、保存并启用规则：

- 每日定时：填写北京时间，如 `08:00, 13:00, 18:00`。
- 额度刷新：可选五小时、每周或任一窗口，检测到符合条件的变化后执行，同一周期去重。
- 运行方式：始终开启，或触发 X 次后关闭；显示已触发次数。按发起发送计数，忙碌跳过不计数。重新启用并保存会重置本轮计数。
- 会话留空：首次创建专用任务，名称为规则名称，ID 自动回填并固定复用；也可填写已有 `codex://threads/…` 链接或 ID。

后续执行会回退到首条消息之前，再发送“你好”，**会移除当前路径的后续历史**，执行前保存本地备份。请绑定专用任务。过期定时不补发，忙碌、账号不符或异常时不会贸然重发。

发送会消耗实际额度；是否开始或改变额度计时由服务端决定，本项目不保证问候一定改变重置时间。

## QQ 对接

1. 先按配套插件 README 安装服务器端。插件首次加载自动生成密钥，重新打开配置页复制。
2. 桌面主窗口打开“AstrBot 推送”，勾选启用远程上传。
3. 填写服务器 `IP:端口`（默认端口 `18765`），或 HTTPS 根地址。
4. **必须填写绑定 QQ 号**，并填入插件生成的相同密钥。
5. 设置上传间隔，范围 15–86400 秒，默认 60 秒，保存后自动生效。

额度仍每分钟采集，上传只发送新结果。长间隔会延迟提醒，超过 3 分钟未采集的数据会被插件标记过期。上传失败按所设间隔重试。

机器人只向绑定 QQ 推送；该 QQ 私聊 `/额度查询` 只会收到自己的额度。推送开关和到期提醒见配套插件 README。

上传含 QQ、账号及卡标识的哈希、额度比例和时间，不含登录凭证或聊天记录。HTTP 使用 HMAC 签名但不加密内容，公网需要保密时使用 HTTPS。服务器密钥只应交给可信的上传端。

## 重置卡

显示只读接口返回的剩余可用次数与到期时间，不会使用或核销重置卡。配套插件在每张卡不足 7 天、不足 24 小时时分别提醒一次。到期提醒需要最近 3 分钟内的有效上传；离线会延迟。

## 数据与排错

运行配置、密钥、QQ、监控状态、历史备份和日志均在自动生成的 `data/` 中，整个目录已被 Git 忽略。**发布源码或报错截图时不要附上该目录。**

- 找不到 Node：安装 Node 并重新启动程序，确认 `node --version` 可用。
- 连接被拒绝：确认插件已启用、服务已监听、Docker 映射接收端口。
- 连接超时：检查地址、服务器安全组及防火墙。
- HTTP 401：确认两端密钥一致、系统时间正常。
- HTTP 400：确认两端均为支持 QQ 绑定的版本，QQ 已填写。
- 未返回某个额度或卡信息：显示未知，不用余额或其他数据推算。

接口或 Codex 版本变化可能影响兼容性。测试覆盖本地额度判断、规则执行、上传重试，以及配套插件的模拟联调；无法保证所有客户端版本均兼容。
